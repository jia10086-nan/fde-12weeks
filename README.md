# fde-12weeks

FDE 12 周学习计划的执行仓库。**这是我自己的学习记录，不用于汇报。**

## 先看哪个文件

| 文件 | 用途 | 什么时候看 |
|------|------|-----------|
| **逐日执行表.md** | ⭐ **主文件**。84 天逐日任务、产出、验收标准 | 每天开工前看当天的 |
| **资源索引总表.md** | 三份资料源该看哪些、跳过哪些、按周取用 | 需要找学习资源时 |
| **每日打卡记录.md** | 每天结束前填一次 | 每天睡前 |
| **每周复盘.md** | 每周日填一次 | 每周日周验收后 |
| **踩坑记录.md** | 遇到问题随手记 | 随时 |
| **第1周环境搭建清单.md** | 环境搭建逐步手册 | 第 1 周 |

## 核心纪律（贴在桌前）

1. **完成的定义是"代码跑起来"**，不是"视频看完了"。
2. **卡住不超过 40 分钟**。超过就记录、求助或绕过去。
3. **每天必须提交 Git**，哪怕只改一行。
4. **看视频和读文档不超过总时间的 30%**，其余 70% 花在键盘上。
5. **每周日做周验收**，不过不进入下一周。
6. **任何技术点，没亲手写过 50 行以上可运行的代码，就不算会。**

## 12 周路线与产出物

| 阶段 | 周次 | 技术主题 | 产出物 |
|------|------|---------|--------|
| 一 | 第 1-3 周 | Python 工程化 + Git + SQL | 一个 200 行以上的命令行工具，上传 GitHub |
| 二 | 第 4-6 周 | LLM API、结构化输出、Function Calling | 日报收集审核服务 |
| 三 | 第 7-9 周 | 切分、向量化、检索、重排、评估 | **能查 SOP 的问答 Agent（主线项目）** |
| 四 | 第 10-12 周 | 容器化、部署、评估、交付 | 端到端交付项目 + 评估报告 |

## 主线项目

**AI 教练培训知识库问答** —— 把交付部门的 SOP 文档、逐字稿、样板课资料做成可问答的知识库。

选择理由：
1. 正好是 FDE 最核心的技能项（RAG 流水线）
2. 解决的是我自己工作上真实的痛点
3. RAG 的三个技术环节正好串起四项缺口
